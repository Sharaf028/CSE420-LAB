# CSE 420 Lab Files

This repository contains the CSE 420 lab files of BRAC UNIVERSITY 

- `LAB-1` - lexical and syntax analysis
- `LAB-2` - symbol table and scope handling
- `LAB3` - semantic analysis
- `LAB-4` - abstract syntax tree, symbol table, and three-address code generation


## Running a Lab file

Open a terminal in the lab directory and run its script:

```bash
cd LAB-1
bash script.sh
```

Use the same pattern for `LAB-2`, `LAB3`, or `420_lab-4`:

```bash
cd LAB-2
bash script.sh
```

```bash
cd LAB3
bash script.sh
```

```bash
cd 420_lab-4
bash script.sh
```

Each script regenerates the parser and scanner sources, compiles the generated files, runs the resulting executable, and displays the relevant output files.
